Política de Privacidade

Fábrica de Cortes · última atualização: 05/11/2026

1. Quem somos

A Fábrica de Cortes é um software de uso pessoal. Ele é operado apenas pelo seu desenvolvedor, em computador próprio, para gerenciar canais de YouTube do próprio operador. Não há outros usuários.

2. Dados que o aplicativo acessa

Quando o operador autoriza um canal com a sua conta Google (OAuth), o aplicativo pode acessar, apenas para essa conta:

  • informações básicas do canal (nome e identificador @);
  • métricas de desempenho do canal, somente leitura (YouTube Analytics);
  • permissão para enviar vídeos ao canal (YouTube upload).

O aplicativo não acessa dados de terceiros, não lê e-mails nem arquivos do Google Drive.

3. Como os dados são usados e guardados

Os dados são usados exclusivamente para publicar vídeos e gerar relatórios de desempenho dos canais do próprio operador. As credenciais de acesso (tokens) ficam armazenadas somente no computador do operador. Os dados não são vendidos, compartilhados, transferidos a terceiros nem usados para publicidade.

4. Serviços de API do YouTube

O aplicativo usa os YouTube API Services. Ao usá-lo, aplicam-se também os Termos de Serviço do YouTube e a Política de Privacidade do Google.

5. Revogar o acesso e apagar dados

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Apagar os arquivos de credenciais do computador remove todo o acesso guardado pelo aplicativo.

6. Crianças

O aplicativo não é direcionado a crianças e não coleta dados de menores.

7. Alterações e contato

Esta política pode ser atualizada; a data no topo indica a versão vigente. Para contato, use os comentários do canal de cortes no YouTube (@espertezaltda).
